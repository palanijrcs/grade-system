# Student Grade System

This Python program asks the user to enter a mark between 0 and 100
and converts the mark into a letter grade.

## Grading Scale

- 90–100: A
- 80–89: B
- 70–79: C
- 60–69: D
- Below 60: E

## Invalid Input Handling

The program checks whether the entered mark is between 0 and 100.
It also handles non-numeric input using exception handling so that
the program does not crash unexpectedly.

## How to Run

python grade_system.py

#Enter your mark (0-100): 85
#Mark: 85 -> Grade: B
